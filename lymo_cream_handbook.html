舒缓数据怎么讲：透明质酸酶是分解皮肤透明质酸的酶，也和过敏反应密切相关。抑制率49.64%（p<0.01）意味着这款能显著抑制透明质酸酶活性——皮肤的透明质酸不容易被破坏，过敏炎症反应同时被抑制。红没药醇 + 灵芝 + 金银花协同做到的。

话术：「舒缓有没有效，看检测报告——49.64%抑制率，p值0.01，数字在那里。」

抗皱数据怎么讲：DPPH自由基清除率52.48%（p<0.01），和松茸悬油精华的57.86%在同一量级。自由基过量导致胶原蛋白氧化降解，皮肤松弛起皱。清除自由基从源头阻断皱纹形成，这是黎沫抗老产品线的统一方向。

话术：「第三方中检科测的，报告编号268GF01572025122365-JC有据可查——数字不会骗人。」
Part 02 · 配方逻辑

精华霜
三层配方结构

霜类产品油脂比例更高，停留时间更长，适合护肤最后一步封层。配方逻辑：发酵底层渗透 → 胶原修护核心 → 中草药稀缺矩阵。

一
双发酵底层 + 多重植物油脂
主播这样理解

和黎沫系列其他产品一样，乳酸杆菌发酵产物排第一位——发酵液底层让霜体活性成分渗透效率更高。牛油果脂 + 角鲨烷 + 霍霍巴籽油三重植物油脂，干皮抹完有被"包裹住"但不油腻的感觉。

乳酸杆菌发酵产物 + 酵母菌/大米发酵产物滤液
黎沫系列贯穿成分，霜体里的发酵底层让活性成分渗透更深，而不是只停留在皮肤表面
牛油果树果脂 + 角鲨烷 + 霍霍巴籽油
三重植物油脂分工：牛油果脂厚实锁水，角鲨烷轻薄渗透，霍霍巴调节皮脂平衡
向日葵籽油 + 沙棘果油
向日葵富含亚油酸修护脂质屏障；沙棘富含维E和胡萝卜素，抗氧化协同
✓ 滋润不腻✓ 渗透效率高✓ 封层持久
二
水解胶原 + 红没药醇 · 修护舒缓核心
主播这样理解

"胶原抗皱"四个字的成分依据在这里：水解胶原蛋白是这款命名的来源；红没药醇是高端舒缓成分，两份检测报告里的舒缓数据有它的贡献。

水解胶原（COLLAGEN）
胶原蛋白水解后的小分子胶原肽，可以渗透皮肤，为皮肤细胞合成新胶原提供原料，同时有保湿和修护功效。产品名"胶原"就来自这里，不是名字加概念
红没药醇（BISABOLOL）
从洋甘菊提取的顶级舒缓成分，抑制炎症介质释放，减少皮肤泛红。舒缓检测报告透明质酸酶抑制率49.64%，是核心贡献成分
尿囊素 + 泛醇（维生素B5）
尿囊素促细胞更新舒缓刺激，泛醇锁水促渗透——和牡丹面膜共用这两个成分，黎沫系列修护体系的一致性
✓ 胶原修护✓ 舒缓有数据✓ 高端成分
三
藏红花领衔 · 中草药稀缺矩阵
主播这样理解

这款的中草药阵容是黎沫系列里最豪华的——藏红花、当归、松茸、灵芝、金银花、苦参、甘草、黄连、黄柏、山竹果皮，每一个都有具体功效，而藏红花是最有话题性的稀缺成分。

番红花（藏红花）花提取物
史称比黄金还贵的香料，每朵只有3根柱头可用，几万朵才能提取1克。护肤功效：藏红花素强效抗氧化 + 辅助提亮均匀肤色，出现在这个价位的霜里是真实的成本投入
当归（ANGELICA SINENSIS）提取物
传统"补血圣药"，当归素促进皮肤微循环，改善气色暗沉，是真正"内调外用"的中药材
松口蘑（松茸）+ 赤芝（灵芝）提取物
和松茸悬油精华共用双菌类成分，系列感强，协同抗氧化促细胞更新
忍冬（金银花）+ 黄葵（苦参）+ 甘草棕醇 + 倒捻子（山竹）果皮
四重抗炎抗氧化协同——金银花清热，苦参抗菌，甘草棕醇温和美白辅助，山竹果皮强效抗氧，和红没药醇一起构建完整舒缓防线

02
藏红花为什么值得单独讲
稀缺性话题 · 最强溢价故事
+
护肤品成分表里出现"番红花花提取物"——这是藏红花，世界上最昂贵的香料之一。

为什么贵？每朵番红花只有3根细长柱头，需要手工采摘，几万朵花才能得到1克，稀缺不是人工制造的，是自然决定的。

护肤功效：藏红花素有极强的抗氧化能力，同时辅助提亮和均匀肤色，是高端抗老产品里越来越常见的成分。

这款工厂直供，没有中间商，这才能在这个价位加进去——消费者在大牌里要付出三倍价格才能用到同等配置。
03
胶原面霜和普通面霜的区别
产品认知 · 名字有没有货
+
市面上很多"胶原面霜"，成分表里根本找不到胶原——只是名字里有个"胶原"。

这款不一样，成分表里有水解胶原（COLLAGEN）。水解是关键——大分子胶原蛋白渗透不进皮肤，水解成小分子胶原肽才能真正进去，为皮肤细胞合成新胶原提供原料。

"胶原抗皱"这四个字，成分表里有真实的胶原。买之前先翻成分表找有没有COLLAGEN——有才叫胶原面霜，没有就是概念。
04
和松茸精华液搭配用
连带销售 · 体系化逻辑
+
松茸悬油精华和这款胶原精华霜，是黎沫抗老线的攻守搭档。

松茸精华液：脂溶性活性成分为主，渗透皮肤深层，集中发挥抗氧化和细胞更新作用。胶原精华霜：精华液之后使用，油脂封层把精华液的成分锁在皮肤里，同时补充水解胶原、藏红花、当归修护和提亮成分。

两款共用松茸、灵芝、山竹果皮——配套设计，精华液进，精华霜留，两步加在一起才是完整的抗老护肤方案。

可以，而且做了舒缓检测。红没药醇是敏感肌护肤品里公认的顶级舒缓成分，透明质酸酶抑制率49.64%（p<0.01）。防腐用1,2-己二醇温和体系。急性过敏期先就医；稳定期敏感肌合适。
水解胶原涂在脸上有用吗？+
水解胶原（胶原肽）外用有效——水解后的小分子肽可以渗透角质层，为皮肤成纤维细胞合成新胶原提供原料，同时有保湿和锁水功效。口服胶原蛋白和外用胶原肽是两条不同路径，互补不是非此即彼。
两份检测报告可信吗？+
两份都是中检科（北京）化妆品技术有限公司出具，是国内权威化妆品功效检测机构。舒缓用透明质酸酶抑制实验，紧致抗皱用DPPH自由基清除实验，都是化妆品行业通用体外功效评价方法，报告编号可查可验。
和松茸悬油精华一起用，顺序是什么？+
顺序：精粹水 → 松茸悬油精华（摇匀） → 胶原精华霜。精华液先渗透，精华霜后封层，30秒内叠用效果最好。
用在哪个步骤？早晚都用吗？+
精华之后、防晒之前（早上），精华之后最后一步（晚上）。早晚都可以，晚上效果最好——夜间皮肤修复最活跃，胶原修护和抗氧化成分夜间工作效率最高。早上用完记得叠防晒。
